# O que é Versionamento Semântico?

O Versionamento Semântico é um sistema de versionamento de software que utiliza três números para indicar o tipo de alteração feita em uma versão. Os três números são separados por pontos e seguem o formato: MAJOR.MINOR.PATCH.

- MAJOR: Indica uma alteração que quebra a compatibilidade com versões anteriores.
- MINOR: Indica uma alteração que adiciona novas funcionalidades, mas mantém a compatibilidade com versões anteriores.
- PATCH: Indica uma alteração que corrige bugs, mas mantém a compatibilidade com versões anteriores.

É utilizado globalmente em diversos segmentos inclusive nos de jogos eletronicos. Ele facilita a comunicação entre os desenvolvedores e os usuários, e depois que você entende fica fácil bater o olho em um projeto e saber quantas versões e alterações foram feitas.
